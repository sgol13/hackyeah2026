# Phone Agent (HackYeah 2026, Huawei challenge)

An AI agent for OpenHarmony / Oniro phones: say what you want ("text grandma that I'll come to her
birthday") and it operates the phone's apps for you through the accessibility framework.

The project lives in [`PhoneAgent/`](PhoneAgent/):

* [README](PhoneAgent/README.md): what it is, exact versions, setup, build, run, verify
* [ARCHITECTURE.md](PhoneAgent/ARCHITECTURE.md): components, agent loop, platform capabilities, error handling
* [AI_WORKFLOW.md](PhoneAgent/AI_WORKFLOW.md): the AI feature (model, data flow, privacy, limits) and how AI tools were used to build it
